# Chetan Nandanwar — Portfolio

Static portfolio site: plain HTML, CSS and JS. No build step.

- `index.html`: home
- `work/`: case studies (Ask Newton has an interactive prototype)
- `colophon.html`: how the site was made
- `assets/css/style.css`: design tokens and all styles

**Run locally:** `python3 -m http.server 4173` → http://localhost:4173

**Deploy:** drag the folder onto Netlify Drop, or import the repo into Vercel / GitHub Pages. No configuration needed.
