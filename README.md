# Chetan Nandanwar — Portfolio

Single-page static portfolio: plain HTML, CSS and JS, no build step.

- `index.html` — all content
- `assets/css/style.css` — design tokens (top of file), layout, animations, light/dark themes
- `assets/js/main.js` — loader, scroll reveals, counters, typed roles, tilt/magnetic effects, hero network canvas

**Run locally:** `python3 -m http.server 4173` → http://localhost:4173

**Deploy:** drag the folder onto Netlify Drop, or push to GitHub Pages / Vercel. No configuration needed.
